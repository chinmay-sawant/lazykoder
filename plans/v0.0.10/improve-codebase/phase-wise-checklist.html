EXT-01: Catalog model metadata does not own protocol routing

P1 / defect
internal/provider/opencode/client.go:77-88, 119-129; internal/modelscache/catalog.go:101-105
Evidence
if isResponsesModel(id) {
    return Route{Endpoint: ResponsesURL(base), Provider: ProviderGo}
}

var responsesModels = map[string]struct{}{
    "gpt-5.6-luna": {},
}
Cost

A new Responses-capable model needs a source edit or it can be sent through the wrong request shape.

Change

Make live and cached catalog protocol metadata own route selection. Keep fallback routing only for records with no protocol metadata.

Proof

Route a synthetic future model with Responses metadata without adding its ID to source.

PRAC-01: Recap entries replace nil contexts with Background

P1 / defect
internal/recap/snapshot.go:87-97; internal/recap/worker.go:53-66; internal/recap/memory_run.go:32-39; internal/recap/memory.go:1061-1066
Evidence
if ctx == nil {
    ctx = context.Background()
}
sess, err := store.GetSession(ctx, sessionID)
Cost

Malformed callers can silently lose cancellation while database, file, or provider work continues after the owning turn is gone.

Change

Define one recap nil-context sentinel and reject nil at cancellation-aware entry points. Keep explicit background roots only in deliberate UI roots.

Proof

Use errors.Is nil-context tests and a cancellation test proving downstream work does not start.
