Priority findings

P0EXT-03defect

Webfetch approves DNS before the actual connection

webfetch.Run resolves a hostname and checks the result before client.Do. The transport resolves again when it dials. A hostname can therefore move from a public address to loopback after approval. The same function overwrites a supplied client's redirect callback and never restores it.

if isPrivateHost(u.Hostname()) { ... }
client.CheckRedirect = func(req *http.Request, via []*http.Request) error { ... }
resp, err := client.Do(req)

Change: one per-call egress client that shallow-copies caller configuration, preserves the original redirect callback, and validates every resolved peer IP immediately before dialing.

Proof: inject a resolver or dialer that changes a hostname to loopback at dial time. Assert no connection, correct redirect validation, and unchanged caller-client behavior under go test -race ./internal/tools/webfetch -count=1.

P1PRAC-01defect

Parallel task calls share a mutable parent session binding

Agent task calls run in separate goroutines. Each call then writes its parent session ID to Host.ParentSessionID before task handlers read it. Parallel calls can associate a job with the wrong parent.

// Host.Execute
h.ParentSessionID = parentSessionID

// Agent.runTools
go func() { results <- a.executeTool(...) }()

Change: treat the parent session as invocation data and pass it to Host handlers. Do not add a mutex that serializes intended task parallelism.

P1EXT-02defect

Declared task result types do not govern Host responses

internal/tools/task defines and encodes result types, but subagent.Host returns a mix of Snapshot, Result, and map-shaped values. One-task and all-task waits differ even though the tool package already owns the response contract.

Change: map Host values to task result structs and call the task encoders for each successful operation.

P1PRAC-04defect

Subagent jobs can start after durable persistence failed

Manager persistence retries a reduced row and discards the final write error. Spawn can then start the runner even though restart, list, wait, cancel, and recovery have no durable job to find.

Change: return the initial persistence error and do not launch the runner until its queued row exists. Surface later write failures to chat instead of claiming the job is restart-safe.

P1EXT-01defect

Child model selection can inherit the wrong endpoint or variant

Manager chooses a child model ID from a spec or role override, then chooses endpoint and variant independently from runtime defaults. A Zen child can therefore be sent to a parent Go route, or inherit a variant that the child model does not support.

Change: resolve child model ID, endpoint, valid variant, and context window as one profile at the chat and model-cache boundary.

P1PRAC-03defect

Agent retains caller-owned tool and bash policy slices

agent.New retains Options directly. A caller can mutate ToolNames or BashAllowlist after construction and change a live Agent's capabilities during a turn.

Change: clone both slices at construction and prove post-construction mutation has no effect.

P1ARC-01friction

Database session creation selects a user-facing model default

db.CreateSession imports settings to fill a missing model, even though Agent, chat, and subagent callers own session identity. Persistence should store the chosen model, not choose one.

if sess.Model == "" {
    sess.Model = settings.DefaultModelID
}

Items intentionally not planned

  • A Provider interface remains refused. There is one production OpenCode provider.
  • Replay continues to use durable db rows while live updates use agent deltas. They are different lifecycles.
  • Subagent depth remains one. No child exposes a nested task host or recovery contract.
  • Child preflight compaction remains disabled until child routing resolves a real context window.
  • The direct session-usage rollup does not reopen the completed SessionGraph work without current contract regression.
